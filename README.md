# NetLupa — descargas

Aquí solo se publican las **versiones compiladas** de NetLupa, un escáner de red con interfaz gráfica para
macOS y Windows. El código fuente no está en este repositorio.

Descarga la última versión en **[Releases](../../releases/latest)**:

| Archivo | Para |
|---|---|
| `NetLupa-macOS-AppleSilicon.zip` | Mac con chip Apple (M1, M2…) |
| `NetLupa-macOS-Intel.zip` | Mac con procesador Intel |
| `NetLupa-Windows.zip` | Windows (carpeta; abre `NetLupa.exe`) |
| `NetLupa-Windows-Portable.exe` | Windows, un solo archivo (guarda sus datos en `NetLupa-datos` a su lado) |
| `SHA256SUMS.txt` | Huellas para comprobar que las descargas están íntegras |

NetLupa busca aquí sus actualizaciones (Ayuda → Buscar actualizaciones).
